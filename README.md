# Рівне коло

Невеликий Android-застосунок для малювання круглого жесту та написання тексту поверх гри. Потрібен Android 12 або новіший (API 31+).

## Як користуватися

1. Відкрийте застосунок і налаштуйте діаметр та швидкість кола. Для тексту введіть до 20 символів і виберіть його розмір.
2. Натисніть **Увімкнути керування** та вручну дозвольте сервіс **Рівне коло** в системних налаштуваннях доступності.
3. Плаваюча панель з'явиться поверх екрана. Перетягніть її за потреби та натисніть **Коло** або **Текст** у грі.

Коло або текст малюються в центрі екрана. Текст відтворюється послідовними жестами за контурами системного Sans-шрифту; довгий напис автоматично зменшується, щоб уміститися на екрані. Сервіс не читає вміст екрана та не виконує жестів без натискання кнопки. Деякі ігри можуть блокувати або переривати синтетичні жести. Параметри зберігаються локально; застосунок не потребує мережевих дозволів.

## Збірка APK

Збірку налаштовано тільки через GitHub Actions — автоматичних запусків на push або pull request немає. Відкрийте **Actions → Android debug APK → Run workflow** і встановіть прапорець явного підтвердження. Якщо прапорець не встановлено, job збірки не запускається. Після завершення APK буде доступний як артефакт `rivne-kolo-debug`.
