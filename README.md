# Рівне коло

Невеликий Android-застосунок для малювання круглого жесту поверх гри. Потрібен Android 12 або новіший (API 31+).

## Як користуватися

1. Відкрийте застосунок і налаштуйте діаметр та швидкість.
2. Натисніть **Увімкнути керування** та вручну дозвольте сервіс **Рівне коло** в системних налаштуваннях доступності.
3. Плаваюча панель з'явиться поверх екрана. Перетягніть її за потреби та натисніть **Малювати** у грі.

Коло малюється в центрі екрана. Сервіс не читає вміст екрана та не виконує жестів без натискання кнопки. Деякі ігри можуть блокувати або переривати синтетичні жести. Параметри зберігаються локально; застосунок не потребує мережевих дозволів.

## Збірка APK

Збірку налаштовано тільки через GitHub Actions — автоматичних запусків на push або pull request немає. Відкрийте **Actions → Android debug APK → Run workflow** і встановіть прапорець явного підтвердження. Якщо прапорець не встановлено, job збірки не запускається. Після завершення APK буде доступний як артефакт `rivne-kolo-debug`.
